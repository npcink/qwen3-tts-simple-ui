# Source origin

This repository was created on 2026-07-20 from a whitelisted snapshot of a
private internal prototype. The private source repository and its Git history
were intentionally not imported.

Excluded from this repository:

- the real inference-host address and Windows installation paths
- deployment task names and operational handoff evidence
- model weights, model caches, SoX and CUDA components
- voice samples, uploads, outputs, logs and consent audit data

Private internal documentation remains the authority for host operations and
acceptance records. This repository is the authority for reusable UI and
adapter source after extraction.
